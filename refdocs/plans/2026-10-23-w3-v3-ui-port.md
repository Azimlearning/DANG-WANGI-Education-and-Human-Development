# Plan: W3, the Synapse V3 UI port

> Workstream W3 of `refdocs/plans/2026-10-22-completion-roadmap.md`. Decisions: D-38 (V3 design language), D-43 (the Kit hardening the review forced). Execution doc: `refdocs/execution/2026-10-23-w3-v3-ui-port.md`. **Written after the build.**

## Why this exists

The owner decided (2026-10-22) that the V4 web app is built on Synapse V3's design and style, with V4's honest labels and the no-unverified-output rule still in force. V4's shell was plain system fonts, one blue accent and a single column.

## Source and what was not taken

Ported from the Genui monorepo at commit `835a2cefda28` (2026-10-05), `Synapse-V3/frontend`: `app/globals.css`, `tailwind.config.ts`, `app/layout.tsx`, `components/TopBar.tsx`, `Mascot.tsx`, `study/StudyRail.tsx`, `study/LabPane.tsx`, `artifact/ProgressStages.tsx`, `artifact/DegradedCard.tsx`, `chat/Composer.tsx`, `chat/MessageList.tsx`, `chat/StreamRenderer.tsx`; intent from `design/BRAND.md`. Every ported file starts with a provenance comment.

V3's own documents disagree with each other: `BRAND.md` says "light only, dark deferred", "not a cartoon mascot", and gamification in the top bar, while V3's code has a theme toggle and Axi and no longer has XP or streaks. The owner's decision (D-38) names Axi and the toggle, so the code and the decision were followed.

Not ported, per D-38: "Watch the code being written" (streams unverified HTML), the "Not fully checked" draft view, the post-hash HTML fitting, saved labs as raw HTML, the "Science checked" badge as a claim (replaced by a badge that follows the Environment's real label), and the XP, streak and gem counters (invented numbers).

## Scope

**In:** tokens, fonts and the chunky button language; the top bar with Axi and a 44 px theme toggle; the study rail (Today's flow, Quick starts, Recently opened); the conversation (turn history, streaming caret); the lab bench column on wide screens with exactly one frame mounted at a time; the progress card driven by the real pipeline layers; the honest label and lane badges; the degraded card; restyled Peek, Stage, Provenance, share page and progress panel; a theme that reaches the Environment's own frame.

**Out, with reasons:** domain and type badges (the schema carries neither; adding them is a wire change, W6 if wanted); Present mode (W6, D-39); the hand-built benches (W4); Bahasa Melayu (W6); a real-phone, keyboard and screen-reader pass (W9).

## Approach

Tailwind 4 `@theme inline` maps the V3 variables to utilities; `next/font` self-hosts Fredoka, Nunito and JetBrains Mono (fetched at build time, served from this origin). The turn list is a pure reducer (`web/lib/turns.ts`). Recently opened items are pointers (id and title) reopened through the delivery gate (`web/lib/recent.ts`). The theme choice is `data-theme` on `<html>`, set before first paint; the host tells each frame with one message and the Kit accepts exactly that shape.

## Risks and unknowns

| Risk | Confidence | Mitigation |
|---|---|---|
| An opaque-origin frame cannot read the host theme, so the toggle needs a Kit change | Measured: Chromium ignores an iframe's `color-scheme` for the embedded page | A closed-set message listener in the Kit, relocked (D-29), reviewed by `kit-guardian`; the review found two older verifier gaps, fixed (D-43) |
| V3's palette fails text contrast in two tokens | Estimated by hand, not measured with a tool | `--ink-faint` and `--warn` darkened; a contrast audit of the whole palette is still owed (W9) |
| The verifier checks the Environment in the light theme only | Known | Recorded as a gap; hiding or overlapping a Kit element in either theme is not audited (it was possible through `prefers-color-scheme` before this work) |
| Fonts need network at build time | Known | `next/font/google`; use `next/font/local` with committed files if an offline build is needed |

## Definition of done

- The web app follows V3's tokens, fonts and chrome; light and dark both render, and the choice reaches the Environment's frame without closing it.
- At 360 px there is no horizontal scroll and every visible control is at least 44 px; at 1280 px exactly one frame is mounted, inside the lab bench.
- No unverified HTML is shown anywhere; the green check appears only for a label at or above `kit-verified`.
- Web, Kit and Python suites, the L6 run, the hostile set and the browser smoke pass, and the review's findings are answered.
