## Deviations and facts worth keeping

- The Kit's CSS audit refuses `background-image`, so a gradient on the mass discs failed `violations()`; the discs are a flat colour.
- The old spring test picked the scene's first `rect`; the stand's base is now first, so it selects the pan by its width. The old orbit tests picked the first `path` and `circle`; they select the main path and Earth by their attributes.
- The ball's place is computed from the drawn path (`getPointAtLength`) and a single `phase` value set in the same call as the attributes, so the audit's exact check always agrees with the page. Where there is no layout engine (jsdom) the ball is held at the cannon.
- `data/environments.pre-w18.db` is the library before this reseed.
