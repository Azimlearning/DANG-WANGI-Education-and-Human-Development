# Router model card (router-v1)

> Generated by `uv run python eval/models/calibrate.py` (do not edit by hand; a test fails if it is stale). Artifact sha256 `e5b7a11292c2a8c47ea769ac3368e9661f92f3518082129668db971035d1f31b`.

## What it is

A multi-head text classifier for the Route stage (D-20). Features: word 1 to 2 gram and character 3 to 5 gram TF-IDF. One logistic regression
per head: **topic** (the 53 syllabus topics plus `none`), **domain**, **pattern** (v3's artifact type) and **complexity**. Weights below
0.1 are dropped and the rest rounded to 4 places, and every number below is for that shipped, pruned model. Inference is pure Python from a JSON
file (no numpy, no network). A router uses a head's answer only above its confidence threshold and sends everything else to the LLM.

## Data and its limits

- Questions and labels come from Synapse v3 (`Azimlearning/GenUI-Education`, `Synapse-V3/ml/router-distill/dataset/clean`, commit `835a2cefda285b4282ea4d0dbf986d1ff08abdb2`).
  They were **written and labelled by an LLM teacher**, not by students or teachers. Held-out accuracy is **agreement with that teacher**, not
  correctness about the world. The v3 notes put the teacher's own agreement with itself at about 75 percent on some styles, which caps what any
  student can show on `pattern` and `complexity`.
- 1821 training, 319 validation, 538 test questions after removing 7 exact duplicates and
  7 training questions that duplicated or nearly duplicated a test question.
- **Stale topic tags.** 303 training and 78 test rows carry a topic tag from an older taxonomy. Their topic is
  unknown, so they are excluded from the topic head only (they still train and test the other heads). Topic accuracy is on 460 test questions.
- `none` means "no syllabus topic tagged in the source" (377 training rows). It is a weak class: some of those questions are in
  fact on-syllabus.
- Domain classes `earth_space` and `math_adjacent` are small (77 and 76 training rows).

## Confidence gate

The threshold for each head is the lowest confidence at which the questions the model answers by itself reach 90.0% accuracy on the
validation set, with at least 20.0% coverage. Test numbers are then measured once, with that threshold fixed.

| Head | Threshold | Validation coverage / accuracy | Test coverage / accuracy | Useful as a gate |
|---|---|---|---|---|
| topic | 0.182 | 93.8% / 90.3% | 92.6% / 88.0% | yes |
| domain | 0.367 | 98.1% / 90.1% | 99.4% / 92.9% | yes |
| pattern | 0.648 | 35.4% / 90.3% | 36.2% / 92.8% | yes |
| complexity | 0.833 | 37.0% / 90.7% | 35.1% / 91.0% | yes |

Coverage is the share of questions the model answers without the LLM. A head that is "not useful as a gate" is not used by the router.

## Do not use it for

- Deciding whether an Environment is correct (it knows nothing about physics).
- Anything unattended below a head's threshold, or on a head marked not useful.
- Questions in Bahasa Malaysia or heavy slang: the training data is English.
- Measuring students: it predicts what an LLM teacher would label.

## Retrain

`uv run python eval/models/data.py build` (needs the v3 clone, set `ROUTER_DATA_DIR`), then `uv run python eval/models/train_router.py`, then
`uv run python eval/models/calibrate.py`. Training takes about two minutes on CPU and is deterministic. A bigger dataset arrives with the full KSSM
ingestion (deferred to local); retrain then and re-read this card.
