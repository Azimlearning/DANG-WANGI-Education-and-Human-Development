# Golden plans

Hand-written golden plans for the first vertical (Physics Form 5, D-18). Each Plan's `citation_ids` name pointers in `data/citations/pointers.json`; the quotations live only beside the local corpus (D-36). A Plan whose every citation proves against the corpus is `kit-verified`; with no corpus, or any citation that does not prove, it is `model-checked` (D-21). A Plan no textbook states goes to `unsupported/`.

Each file is a `Plan` (api/pipeline/plan.py). They are the fake planner's answers and the fixtures that prove plan checks, assembly and verification end to end.
